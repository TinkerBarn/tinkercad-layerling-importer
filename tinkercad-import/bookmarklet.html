Tinkercad to layerling

  1. Open the design in the Tinkercad editor.
  2. Drag this link to the bookmarks bar: Export to layerling
  3. Click the bookmark. If the editor tools need enabling, the page reloads; click it again when the design is ready. The browser downloads tinkercad-design.json, including evaluated geometry and available surface normals for every part and boolean group. Missing geometry stops the export.
  4. Turn the file into a project: python3 convert.py tinkercad-design.json -o design.lyl
  5. Open design.lyl in layerling (File → Open, or drop it on the window).

If a bookmark is awkward, copy the same script and paste it into the editor’s console.

When you are finished, run TinkerPower.delete("testkit") in that console to turn the editor tools back off.
