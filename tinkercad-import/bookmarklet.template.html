Tinkercad to layerling

Version {{VERSION}} preview · Local conversion · No server or Python required

Replace your saved bookmark after installing an update.

  1. Open the design in the Tinkercad editor.
  2. Drag this link to the bookmarks bar: Export to layerling
  3. Click the bookmark. If the editor tools need enabling, the page reloads; click it again when the design is ready. It captures the evaluated design and downloads a Layerling .lyl file. Missing geometry stops the export.
  4. Open the downloaded .lyl in layerling (File → Open, or drop it on the window).

Design capture and conversion stay in your browser. GitHub hosts this page and has its own hosting logs. Imported parts are editable meshes, not recovered sketches. This unofficial preview uses undocumented Tinkercad editor tools; large designs require available memory.

Advanced troubleshooting

If a bookmark is awkward, copy the script and paste it into the editor’s console. For a JSON troubleshooting export, run exportTinkercadDesign() in the console after the bookmark has run.

When you are finished, run TinkerPower.delete("testkit") in that console to turn the editor tools back off.
